Default install serves UI + API on port 2026.
This console is served from its own origin, so the gateway must allow it.
BEFORE GOING LIVE DeerFlow ships with CORS off (same-origin only). Start the gateway with your console's origin allow-listed:

GATEWAY_CORS_ORIGINS=<this-page-origin> make dev

Opened as a local file? Serve it instead: python -m http.server 4173 then allow http://localhost:4173.

IF YOU GET 401s The gateway's auth is on. Either sign in to DeerFlow's own UI in this browser first (localhost cookies are shared across ports — this console rides the same session and CSRF token), or for local dev start the gateway with DEER_FLOW_AUTH_DISABLED=1.
